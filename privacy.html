隐私与数据说明

本页说明职引者在生成求职诊断时处理哪些数据、数据流向哪里、保留多久，以及如何删除。 使用前请先阅读；点击“生成求职诊断报告”即表示你已理解并同意以下处理方式。

1. 处理哪些数据

  • 你上传的简历 PDF，以及从 PDF 中提取出的文字；
  • 你粘贴或编辑的简历文字；
  • 你粘贴的目标岗位招聘要求。

请勿在简历或岗位文本中填写身份证号、银行卡号、家庭住址等与求职诊断无关的敏感信息。

2. PDF 在哪里解析

简历 PDF 在浏览器中本地解析，文件本身不会上传到任何文件存储服务。解析出的文字会进入下一步分析。

3. 文字发送到哪里

在本地演示环境中，浏览器将简历文字和岗位文字发送给本机运行的 Node 服务（默认 127.0.0.1:3000），再由该服务转发给 DeepSeek API 完成岗位评分表提取和简历证据核对。 若启用浏览器直连模式，则由浏览器直接请求 DeepSeek API。生成模拟面试题时会发送岗位要求和相关证据，点评时也会发送作答内容。无论哪种方式，发送的文字都会离开本机并受 DeepSeek 服务条款和隐私政策约束。

本项目不提供账号系统，不接入统计分析或广告服务，也不会把简历文件上传到对象存储。

4. 本地保存什么、保留多久

  • 浏览器会话存储：当前输入的简历、岗位文字、诊断报告和模拟面试记录保存在 sessionStorage 中，关闭标签页后自动清除。
  • 服务端分析缓存：使用 SQLite 缓存同一简历与岗位的分析结果，避免重复调用模型。 缓存包含分析结论、报告中引用的简历原句、模型与协议版本、token 用量和内容哈希，不单独保存完整的简历与岗位原文。
  • 保留期限：默认最多保留 30 天（可通过环境变量 CACHE_TTL_DAYS 调整），服务启动时会清理过期记录。相同材料再次分析会命中缓存，勾选“忽略缓存”才会重新调用模型。
  • 调用审计：默认只记录请求哈希和 token 用量；只有显式设置 LOG_RAW_RESPONSES=1 时才保存模型原始返回内容，用于调试。

5. 如何删除

在诊断报告页右上角点击“删除本次记录”。系统会按简历与岗位原文定位并删除服务端对应的分析缓存、 与该次分析关联的调用日志，同时清空当前标签页中的输入、报告和模拟面试。删除操作不可撤销。

如果报告页打不开或无法连接本地服务，你也可以直接删除缓存文件 data/cache.db（以及同目录下的 -wal、-shm 文件），或等待超过保留期限后由系统自动清理。

6. 结果如何使用

诊断结果仅用于求职材料自查和面试准备，不构成录用承诺或法律意见。分数由固定规则程序计算， 模型只负责提取岗位要求和简历证据，不直接给出总分。
