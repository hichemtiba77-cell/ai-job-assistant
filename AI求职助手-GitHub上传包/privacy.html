隐私与数据说明

本页说明职引者在生成求职诊断时处理哪些数据、数据流向哪里、保留多久，以及如何删除。 使用前请先阅读；点击“生成求职诊断报告”即表示你已理解并同意以下处理方式。

1. 处理哪些数据

  • 你上传的简历 PDF，以及从 PDF 中提取出的文字；
  • 你粘贴或编辑的简历文字；
  • 你粘贴的目标岗位招聘要求。

请勿在简历或岗位文本中填写身份证号、银行卡号、家庭住址等与求职诊断无关的敏感信息。

2. PDF 在哪里解析

简历 PDF 和扫描页图像在浏览器中处理。扫描页的识别文字可在提交前核对和修改。生成诊断时，系统先遮盖可识别的姓名、手机号、邮箱、证件号、社交账号和住址，再提交处理后的文字。发送前会显示脱敏预览，可继续编辑。自动识别可能遗漏自由格式的个人信息，请复核后再确认发送。选择离线检查时，材料只在浏览器内处理。

3. 文字发送到哪里

在本地演示环境中，浏览器将简历文字和岗位文字发送给本机运行的 Node 服务（默认 127.0.0.1:3000），再由该服务转发给 DeepSeek API 完成岗位评分表提取和简历证据核对。 双击打开本地页面并配置测试密钥时，由浏览器直接请求 DeepSeek API。无论哪种方式，文字都会离开本机并受 DeepSeek 服务条款和隐私政策约束。

本项目不提供账号系统，不接入统计分析或广告服务，也不会把简历文件上传到对象存储。

4. 本地保存什么、保留多久

  • 浏览器会话存储：脱敏后的简历、岗位文字和诊断报告保存在 sessionStorage 中，关闭标签页后自动清除。
  • 服务端分析缓存：默认在进程内保存最多 30 分钟，重启服务即清空。缓存报告含脱敏后的证据引用、评分和 token 用量。
  • 可选磁盘缓存：设置 CACHE_PERSIST=1 后，缓存可跨重启复用。默认保留 30 天，可通过 CACHE_TTL_DAYS 调整。服务定期清理过期记录。服务不保存新的模型原始返回或逐次调用日志。

5. 如何删除

在诊断报告页右上角点击“删除本次记录”。新版报告使用随机删除凭证定位本机分析缓存，并清空当前浏览器的输入和报告。旧版报告仍通过对应材料删除缓存和关联日志。岗位评分表单独按保留期限清理。此操作无法撤回已发出的模型请求。

服务无法连接时，可以恢复连接后重试。若曾启用磁盘缓存且要清空全部本地分析，可先停止服务，再删除缓存文件 data/cache.db（以及同目录下的 -wal、-shm 文件），或等待超过保留期限后由系统自动清理。

6. 结果如何使用

诊断结果仅用于求职材料自查和面试准备，不构成录用承诺或法律意见。分数由固定规则程序计算， 模型只负责提取岗位要求和简历证据，不直接给出总分。
