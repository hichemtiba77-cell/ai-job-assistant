# PDF简历生成功能方案

## 一、功能定位

用户不是直接提交一份文字和个人照片就获得最终PDF，而是经过“识别内容 → 选择模板 → 编辑确认 → 预览 → 导出”的过程。

完整流程：

```text
粘贴或导入简历文字
→ 系统整理为基本信息、教育、项目、实习、技能等结构
→ 用户选择模板
→ 用户在编辑器中修改文字、顺序和照片
→ 实时预览
→ 用户确认内容真实
→ 导出PDF
```

## 二、第一版建议功能

### 模板

第一版制作3套原创模板：

1. 校招单栏简洁版：适合大多数校招和实习，ATS可读性好。
2. 技术项目强化版：突出项目、技能和成果。
3. 研究生科研版：突出教育、科研、论文、项目和实践。

模板应使用项目自己设计或明确授权的版式，不直接下载第三方商业模板。

### 编辑器

- 按模块编辑基本信息、教育、项目、实习、技能。
- 调整模块顺序。
- 修改文字并实时预览。
- 上传个人照片并调整大小、位置和裁切。
- 切换模板而不重新输入内容。
- 导出前提示检查错别字和真实性。

第一版可以先不做拖拽排版，使用上下移动按钮即可。

### PDF导出

最稳妥的第一版方案是使用浏览器打印样式导出PDF：

- 不增加额外后端。
- 中文字体由浏览器和系统提供。
- 用户可以正常预览和打印。
- 页面尺寸固定为A4。

后续如果模板变复杂，再考虑专门的服务端PDF渲染。

## 三、内部数据结构

为了支持不同模板，不能直接把整段文字塞进HTML。应把简历保存成结构化数据：

```json
{
  "templateId": "campus-clean",
  "profile": {
    "name": "",
    "phone": "",
    "email": "",
    "photo": ""
  },
  "sections": [
    {
      "type": "education",
      "title": "教育经历",
      "items": []
    },
    {
      "type": "projects",
      "title": "项目经历",
      "items": []
    }
  ]
}
```

AI之后只负责帮助整理和优化字段，不直接操纵PDF底层排版。模板负责把结构化数据展示成页面。

## 四、AI应该做什么

DeepSeek适合：

- 将用户原始文字整理成简历模块。
- 调整措辞，使表达更具体。
- 提示缺少时间、职责、规模或结果。
- 根据目标岗位提出可选的表达建议。

DeepSeek不应该：

- 编造学历、技能、实习和项目。
- 自动替用户补充不存在的数字。
- 未经确认覆盖用户原文。
- 直接输出不可编辑的最终PDF。

每次AI建议都应支持“接受、修改后接受、忽略”。

## 五、开发顺序

1. 先设计一套结构化简历数据格式。
2. 做一套原创A4模板和实时预览。
3. 做文字编辑、照片和主题色调整。
4. 完成浏览器PDF导出。
5. 再增加第二、第三套模板。
6. 最后加入DeepSeek排版与措辞建议。

这样可以先在没有AI的情况下验证编辑和PDF效果，避免把排版能力绑死在模型输出上。

## 六、验收标准

- 用户可以在导出前修改所有文字。
- 照片可以上传、调整和删除。
- 页面始终为A4尺寸，不出现内容截断。
- 切换模板后内容和照片不丢失。
- 中文、英文和数字显示正常。
- 导出的PDF文字可复制、可搜索。
- 用户明确确认内容真实后再导出。
